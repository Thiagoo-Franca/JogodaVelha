# ❌⭕ Jogo da Velha (Tic-Tac-Toe)

Um jogo da velha clássico desenvolvido para navegador utilizando HTML, CSS e JavaScript puro (Vanilla JS). Este projeto foi criado como exercício prático durante os meus estudos iniciais de desenvolvimento web front-end, com o objetivo de consolidar a lógica de programação, a estilização de interfaces e a manipulação dinâmica do DOM.

## ✨ Funcionalidades

Modo Dois Jogadores (Local): Alternância automática de turnos entre os jogadores X e O.

Verificação de Resultado: Detecção automática de vitória (linhas, colunas e diagonais) e de empate ("deu velha").

Reinício de Partida: Botão dedicado para limpar o tabuleiro e iniciar um novo jogo rapidamente.

Interface Responsiva: Layout centralizado e adaptável para diferentes tamanhos de tela (desktop e mobile).

## 🛠️ Tecnologias Utilizadas

HTML5: Estruturação semântica dos elementos da página e do tabuleiro.

CSS3: Estilização visual, alinhamento utilizando Flexbox/CSS Grid e efeitos visuais de interação.

JavaScript (ES6+): Gerenciamento do estado do jogo, eventos de clique e lógica de verificação das condições de vitória.

## 🚀 Como Executar o Projeto

Como o projeto foi construído apenas com tecnologias web nativas, não há necessidade de instalar pacotes ou dependências:

### Clone este repositório:

git clone https://github.com/Thiagoo-Franca/JogodaVelha.git


### Acesse o diretório do projeto:

cd JogodaVelha


## Execute o jogo:

Dê um duplo clique no arquivo index.html para abri-lo diretamente no seu navegador, ou

Utilize a extensão Live Server no VS Code para rodar o projeto localmente.

## 🧠 Principais Aprendizados

Durante a construção deste projeto, pude praticar na prática conceitos essenciais do desenvolvimento front-end:

Seleção de elementos HTML e escuta de eventos com JavaScript (querySelectorAll, addEventListener).

Uso de arrays e estruturas condicionais para mapear as posições do tabuleiro e validar combinações vencedoras.

Organização de código separando estrutura (HTML), estilo (CSS) e comportamento (JavaScript).
